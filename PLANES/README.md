# PLANES

Todo el planeamiento del proyecto vive acá, versionado en git. Nada de planificar en un
chat y perderlo.

## Convención

- Nombre de archivo: `YYYY-MM-DD-tema.md`
- Cada plan arranca con una línea `**Estado:**` que se actualiza a medida que avanza:
  `propuesto` → `aprobado` → `en curso` → `completado` (o `descartado`)
- Un plan descartado **no se borra**: se marca como tal y se anota por qué. La decisión que
  no tomamos es tan útil como la que tomamos.
- Los cambios de rumbo van como un plan nuevo que referencia al anterior, no editando el
  viejo hasta volverlo irreconocible.
